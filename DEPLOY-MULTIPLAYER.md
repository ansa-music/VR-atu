# VR-ATU: запуск сетевого сервера

Клиент: https://ansa-music.github.io/VR-atu/

## Первый запуск на Render
1. Подключите GitHub к Render.
2. Откройте https://dashboard.render.com/blueprints и выберите New Blueprint Instance.
3. Выберите репозиторий `ansa-music/VR-atu` и `render.yaml`.
4. Подтвердите создание бесплатного сервиса. Render построит контейнер из `server/Dockerfile`.
5. После развёртывания проверьте `https://<actual-service-host>/health`, должно возвращать JSON `{"ok":true,...}`.
6. Замените пустую строку `MULTIPLAYER_SERVER_URL` в `js/server-config.js` на настоящий URL `wss://<actual-service-host>` и сохраните в `main`.
7. Подождите подтверждения публикации GitHub Pages и протестируйте комнату с двух разных устройств.

На странице игры после этого **не нужно** вводить адрес сервера — клиент прочитает его из конфигурации.

Render Free может засыпать через 15 минут простоя; первое подключение иногда запускает холодный старт. Комнаты хранятся в памяти и теряются при перезагрузке сервиса. Для постоянных игр нужен платный/постоянный хостинг.

Пока адрес в конфигурации пустой, кнопки создания и входа не смогут подключиться; для локальных разработчиков сохранена ручная настройка в сворачиваемом разделе.
