# ATU — Академия магов

16 готовых GLB 2.0 в едином стилизованном low-poly аниме-фэнтези оформлении: гранёные кристаллы, тёмный камень, золотые ободки, циановые и фиолетовые руны. Это статические процедурные модели без скелетов и анимации. Превью показывает геометрию и цвета; это ортографический программный рендер без bloom.

## Подключение

Загружайте соответствующий `.glb` обычным glTF-загрузчиком вашего движка. Все данные, включая PNG, встроены в GLB. Дополнительные файлы и расширения glTF не нужны.

- Единицы: метры. Y вверх, направление вперёд −Z. Масштаб корневого узла 1.
- В каждом файле один mesh, один primitive, один материал, одна текстура. Текстуры 1024×1024; wisp, fairy, skull, rune-target и mana-crystal — 512×512.
- Один и тот же атлас используется для baseColorTexture и emissiveTexture. TEXCOORD_0 задаёт цвет поверхности; TEXCOORD_1 переводит несветящиеся полигоны в чёрную область атласа. При переработке материала сохраняйте оба UV-канала.
- Все оружейные модели имеют начало координат в центре хвата. Посох расположен вдоль −Z: при удержании его вертикально поверните оружейный объект в игровом коде. Лук расположен в плоскости YZ, стреляет вдоль −Z.
- Muzzle, String, Tip, Crystal и WeakPoint — именованные пустые дочерние узлы корневого mesh. Их координаты указаны в manifest.json. Локальное направление узлов −Z; у перчатки Muzzle расположен у кристалла ладони.
- У противников основание модели находится около Y=0. Платформа имеет плоскую верхнюю поверхность Y=0; руническая инкрустация выступает примерно на 2 см. Коллайдер верхней площадки задавайте отдельно на Y=0.
- Печать ATU лежит в XY, лицевая сторона смотрит в −Z. Размеры 4,5×2,3 м; толщина с рельефными буквами около 12 см. Для размещения на полу поверните объект вокруг X.
- Blade использует alphaMode=BLEND: прозрачность только в области атласа лезвия; рукоять и гарда непрозрачные. Возможна обычная для alpha blend сортировка пересекающихся поверхностей.
- Emissive создаёт самосветящийся цвет. Ореол вокруг объектов добавляется bloom-проходом в игре; эти модели не содержат источников света.

## Оптимизация для Quest

Все модели существенно ниже заданных лимитов треугольников. Нет костей, морфов, анимаций, внешних ресурсов и обязательных расширений. Число треугольников, реальные габариты, узлы и размер каждого файла приведены в manifest.json.

PNG хранится с обычным сжатием. После декодирования текстура RGBA 1024×1024 занимает около 4 МиБ без mipmaps; 512×512 — около 1 МиБ. Поэтому число одновременно загруженных объектов и экземпляров всё равно имеет значение. Повторные экземпляры должны разделять геометрию и текстуры; для большого количества декора используйте instancing. Для итогового билда можно отдельно подготовить KTX2/BasisU под выбранный загрузчик.

GLB проверены локальным validate_assets.py: структура, встроенные ресурсы, геометрия, нормы, UV, имена узлов и лимиты. Результат — validation.json. На физическом Meta Quest и в вашем WebXR-приложении модели не тестировались; FPS зависит также от освещения, прозрачности, постобработки и количества объектов.

## Воспроизведение и изменение

Готовые GLB можно импортировать в Blender 4.x через File → Import → glTF 2.0. Геометрию, материалы и пустые узлы можно редактировать как обычные объекты. Перед повторным экспортом сохраняйте имена точек, масштаб и оба UV-канала.

Исходный генератор работает напрямую в Python, без Blender:

```text
pip install pillow numpy
python generate_assets.py
python validate_assets.py
```

Генератор перезаписывает 16 GLB, manifest.json и preview.png рядом со скриптом. Цвета задаются в PALETTE, геометрия — в make_models(). Текстура генерируется процедурно. Все модели созданы для этого набора; сторонние модели, изображения и шрифты в GLB не используются. Буквы ATU состоят из геометрии.
