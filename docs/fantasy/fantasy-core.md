# fantasy-core (аккаунт 1 «Ядро») — сводка

## Готово (этап 0 + навыки)
- **Режим** `settings.mode`: `'fantasy'` (по умолчанию) | `'realism'`. Действует только в шлеме; на ПК и телефоне всегда реализм. Переключение: панель «✦ Фэнтези / Реализм» под VR-меню (выстрел или курок по кнопке) и строка «Режим в VR» в блоке «Настройки».
- **Мана игрока** 100, восстановление 5/с. Мана оружия — отдельно (аккаунт 3).
- **Навыки** (`js/fantasy/skills.js`), всё в шлеме:
  | Навык | Как вызвать | Мана / откат |
  |---|---|---|
  | Мгновенный шаг | левый стик вперёд → дуга от левой руки → отпустить | 8 / 0,35 с |
  | Энергосфера | свободная рука ладонью вверх + хват, бросок рукой (быстрее 1,2 м/с) | 15 (+дозаряд) / 1 с |
  | Волна ки | обе руки перед животом, оба хвата 1,5 с, толчок вперёд | вся мана (≥ 40) / 6 с |
  | Ускорение восприятия | коснуться наруча (левое запястье) правой рукой без хвата | 30 / 15 с; мир ×0,25 на 4 с |
  | Барьер | свободная рука ладонью вперёд + хват | 5 + 10/с |
  | Небесный шаг | A в воздухе, до 3 раз | 6 |
  | Руны | курок свободной руки зажат — рисовать: круг — щит-купол 4 с, треугольник — огненный шар, зигзаг — молния (до 3 целей), спираль — +40 маны (раз в 15 с) | 20 / 15 / 20 / 0 |
  | Ульта «Пробуждение» | шкала от попаданий, оба хвата + курок руки с оружием | 8 с: очки ×2, урон ×2, купол |
- **Стоп-кадр** 50–80 мс на сильных ударах (волна ки, взрыв большой сферы, молния, ульта): мир стоит, голова и руки двигаются, камеру не трясём.
- **Платформы**: мгновенный шаг встаёт на `world.platforms` (верх платформы), с края платформы игрок падает.
- **Оптимизация VR**: DOM-интерфейс в шлеме прячется один раз и больше не обновляется; модель у камеры и сенсорное управление в шлеме не работают; FPS — на наруче (в реализме — табличка у наручного экрана).
- **Модели**: `loadModel(id)` из `js/fantasy/assets.js` → `Promise<Object3D | null>`, каждый раз копия. Готовые модели перечислены в `assets/models/models.json` (`["wand", "bow"]`) — положили `.glb`, допишите id, иначе загрузчик его не ищет (так в консоли нет 404). Ещё `findNode(root, 'Muzzle')`.
- `vendor/addons/loaders/GLTFLoader.js`, `vendor/addons/utils/BufferGeometryUtils.js` — из three@0.160.0.

## Как подключаются модули аккаунтов 2 и 3
В `main.js` есть `FANTASY_READY = { world, ui, bracer, audio, enemies, waves }` — после слияния ветки ядро ставит `true`, и модуль грузится (иначе в консоли был бы 404). Уже подключено по договору API из `docs/FANTASY-PLAN.md`:
- `world`: `createFantasyWorld(scene, { quality })`, `setVisible`, `update(dt, time)` (dt уже с замедлением мира), `platforms` для шага.
- `bracer`: `createBracer()` на левом контроллере, вместо заглушки; `update({ mana, maxMana, skills, ult01, score, timeLeft, weapon: { name, mana01 }, fps })`.
- `audio`: `playSpell(name)` — имена из плана; пока модуля нет, звучат похожие звуки из `sfx.js`.
- `enemies`: пока только `projectiles` (барьер и купол-щит отражают снаряды через `deflect(p, dir)`; у снаряда ожидается `position` или `mesh.position`).
Остальное (меню и табло фэнтези, оружие, лук, клинок, противники, волны) ядро подключит при слиянии по сводкам веток.
