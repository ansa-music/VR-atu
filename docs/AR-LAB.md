# СӨЖ: интерактивті WebAR жоба — «ATU AR-бестиарийі»

**Сілтеме / Ссылка:** https://ansa-music.github.io/VR-atu/ar.html
**Маркер:** https://ansa-music.github.io/VR-atu/assets/ar/marker.png
**Камерасыз демо / Демо без камеры:** https://ansa-music.github.io/VR-atu/ar.html?demo

## Жобаның сипаттамасы (қазақша)

**Жобаның аты:** «ATU AR-бестиарийі» — VR-ATU ойынының кейіпкерлерін толықтырылған шындықта таныстыру.

Жоба телефон браузерінде ашылады, қосымша орнатудың қажеті жоқ. Қолданушы камераны Академия эмблемасына бағыттайды, сонда ойындағы 3D жаратылыс эмблеманың үстінде пайда болады.

Қолданылған құралдар:

1. **3D модель қосу (3D Object Upload).** Ойынның GLB форматындағы бес моделі жүктеледі: Академия күзетшісі, Игнарок алыбы, Пері, Бас сүйек-күзетші және Көз (`assets/models/*.glb`). Модельдер маркердің еніне сәйкес автоматты түрде масштабталады.
2. **Image Tracking (сурет арқылы тану).** Триггер ретінде ATU эмблемасы бар сурет қолданылады (`assets/ar/marker.png`). Камера суретті таныған кезде модель дыбыспен бірге пайда болады, сурет көрінбей қалса — жасырылады.
3. **Action Script (қимылдарды басқару).**
   - Модельді түрткенде дыбыс шығады, модель секіріп, бір айналым жасайды, ұшқындар шашырайды.
   - Камераны маркерге жақындатқанда жаратылыс «оянады»: үлкейеді, қызарып жарқырайды, дыбыс шығарады. Алыстағанда қайта «ұйықтайды».
   - «Существо» батырмасы келесі модельге ауыстырады.
   - «Стена / Стол» батырмасы модельдің қалпын өзгертеді (маркер қабырғада/экранда немесе үстелде жатыр).
   - «В игру» батырмасы басқа бетке — ойынның басты бетіне өткізеді.

Қалай тексеруге болады: маркерді компьютер экранында ашыңыз (немесе басып шығарыңыз), телефонда сілтемені ашып, «Запустить AR» батырмасын басыңыз және камераға рұқсат беріңіз.

Ескерту: тапсырмада Web-AR.Studio платформасы көрсетілген. Бұл жоба сол үш құралды (3D модель, Image Tracking, Action Script) өз кодымызбен, ашық MindAR және Three.js кітапханалары арқылы жүзеге асырады және GitHub Pages-те орналасқан.

## Описание проекта (по-русски)

**Название:** «AR-бестиарий ATU» — знакомство с существами игры VR-ATU в дополненной реальности.

Проект открывается в браузере телефона, установка не нужна. Пользователь наводит камеру на эмблему Академии, и над ней появляется 3D-существо из игры.

Использованные инструменты:

1. **Загрузка 3D-модели.** Пять GLB-моделей из игры: Страж Академии, Колосс Игнарок, Фея, Череп-страж, Око (`assets/models/*.glb`). Модели автоматически подгоняются под ширину маркера.
2. **Image Tracking.** Триггер — изображение с эмблемой ATU (`assets/ar/marker.png`). Когда камера узнаёт картинку, модель появляется со звуком; когда картинка пропадает — скрывается.
3. **Action Script.**
   - Касание модели: звук, прыжок, полный оборот и искры.
   - Приближение камеры к маркеру: существо «просыпается» — увеличивается, светится красным, издаёт звук. При отдалении «засыпает».
   - Кнопка «Существо»: следующая модель.
   - Кнопка «Стена / Стол»: поза модели (маркер на стене/экране или лежит на столе).
   - Кнопка «В игру»: переход на другую страницу — главный экран игры.

Как проверить: открыть маркер на экране компьютера (или распечатать), на телефоне открыть ссылку, нажать «Запустить AR» и разрешить камеру.

Оговорка: в задании указана платформа Web-AR.Studio. Здесь те же три инструмента сделаны своим кодом на открытых библиотеках MindAR и Three.js, страница размещена на GitHub Pages.

## Для разработки

- Страница: `ar.html`. Трекер: `vendor/mindar/` (MindAR 1.2.5, MIT). Маркер: `assets/ar/marker.png` и скомпилированный `assets/ar/marker.mind`.
- Пересобрать маркер: открыть `tools/ar-marker.html`, скачать оба файла и положить в `assets/ar/`. В фоновой вкладке добавить `?bg`.
- Камера работает только по HTTPS или на localhost. `ar.html?demo` показывает сцену без камеры (вращение мышью, колесо — приближение).
- Отладка: `window.arLab` — состояние (`found`, `awake`, `distance`, `taps`, `creature`, `pose`), `arLab.step(n)` прогоняет кадры вручную.
