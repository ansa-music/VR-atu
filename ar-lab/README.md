# Лабораторная №12 — WebAR «Ғарыш порталы» (AR.js + A-Frame)

**Открыть на телефоне:** https://ansa-music.github.io/VR-atu/ar-lab/
**Маркеры для печати:** https://ansa-music.github.io/VR-atu/ar-lab/markers/print.html

Маркер на столе превращается в **дыру-портал**: внутри космос со звёздами и планетой с кольцами, из портала вылетает НЛО (glTF-модель).
Второй маркер (⚡) переключает мир за порталом на **океан**: там плавают рыбы, поднимаются пузыри, одна рыба выпрыгивает из дыры.

Вариант: **№10 «Музейный экспонат»** (3D-модель + анимация + текстовая справка-табличка).

## Проверка без камеры (тест-режим)
AR.js ищет маркер на готовой картинке вместо видео. Открывайте в режиме телефона (F12 → Toggle device toolbar), потому что кадры портретные:
- [?test=test/key.jpg](https://ansa-music.github.io/VR-atu/ar-lab/?test=test/key.jpg) — открытый портал (космос);
- [?test=test/both.jpg](https://ansa-music.github.io/VR-atu/ar-lab/?test=test/both.jpg) — два маркера, мир переключён на океан;
- [?test=test/empty.jpg](https://ansa-music.github.io/VR-atu/ar-lab/?test=test/empty.jpg) — маркера нет.

## Локальный запуск
Из папки `ar-lab`:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000 и покажите в веб-камеру маркер с ключом.

## Как работает «дыра в столе»
- **Маска-окклюдер** (компонент `occluder`): плоскости вокруг маркера с `colorWrite = false`. Они не рисуют цвет, а только заполняют буфер глубины. Поэтому всё «под столом» видно только сквозь отверстие, а вокруг остаётся изображение с камеры.
- **Шахта** — куб, у которого рисуются только внутренние стенки (`side: back`), с градиентом.
- **Крышка** — тот же окклюдер поверх отверстия. По `markerFound` она сжимается, и портал «открывается».

## Соответствие критериям оценки

| Критерий | Баллы | Что сделано |
|---|---|---|
| Маркер распознаётся, 3D видно | 30 | портал, НЛО, планета, звёзды |
| Свой маркер | 15 | два своих pattern-маркера (🔑 и ⚡), `.patt` + PNG |
| Вариант выполнен | 25 | вариант 10: glTF-модели, анимация, текстовая табличка-экспонат |
| Анимация и события | 10 | `markerFound` / `markerLost` (компонент `portal-controller`), более 10 анимаций |
| Качество кода | 5 | компоненты с понятными именами, комментарии на казахском |
| Бонусы | + | звук при обнаружении маркера (Web Audio); второй маркер меняет содержимое первого; нажатие на НЛО или рыбу меняет цвет (`cursor` + `raycaster`) |

## Перегенерировать маркеры или модели
Из папки `ar-lab`:

```bash
python tools/make_markers.py .
```

```bash
python tools/make_models.py .
```

Чтобы сделать маркер со своим рисунком, поменяйте функции `draw_key` / `draw_bolt` в `tools/make_markers.py`. Рисунок должен быть контрастным и **не симметричным при повороте**.
