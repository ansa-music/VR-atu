# VR Тир

Браузерный VR-тир на **WebXR** и **Three.js**: стреляйте по мишеням, перемещаясь от первого лица. Можно играть в VR-шлеме, на обычном ПК и с самодельным контроллером на **Arduino** (джойстик + кнопка), который подключается к игре через **Web Serial**.

**Играть онлайн:** https://ansa-music.github.io/VR-atu/

## Запуск локально

Нужен только Python 3 (Node.js не требуется).

1. Дважды щёлкните `start.bat`
   или выполните в папке проекта:
   ```bash
   python -m http.server 8000
   ```
2. Откройте в браузере http://localhost:8000

## Управление

| Где | Движение | Обзор / поворот | Выстрел |
|-----|----------|-----------------|---------|
| ПК | WASD | мышь | клик мыши или Пробел |
| VR | левый стик | правый стик (поворот рывками) | курок |
| МК (Arduino) | джойстик | — | кнопка джойстика |

## Контроллер на микроконтроллере

- Скетч: [`arduino/vr_tir_mk/vr_tir_mk.ino`](arduino/vr_tir_mk/vr_tir_mk.ino) — Arduino Uno/Nano, джойстик KY-023, светодиод, пищалка (необязательно).
- Таблица подключения проводов — в комментарии в начале скетча.
- Загрузите скетч через Arduino IDE (плата Uno/Nano, нужный COM-порт, кнопка «Загрузить»).
- В игре нажмите **«Подключить МК»** (Chrome или Edge на ПК) и выберите COM-порт платы.
- Протокол: МК отправляет строки `J,x,y,b` на скорости 115200 бод; игра отвечает символами `H`/`G`/`B`/`S`/`E`/`P` (попадание, золотое попадание, бомба, старт, конец раунда, пинг).

## Важно

- Режим VR и Web Serial работают только по **HTTPS** или на **localhost** — поэтому в шлеме открывайте ссылку GitHub Pages.
- Web Serial есть только в настольных **Chrome/Edge**. Чтобы играть в VR с контроллером на МК, используйте ПК-VR: подключите шлем к компьютеру через Quest Link / Air Link и откройте игру в Chrome/Edge на ПК.

## Технологии

Three.js 0.160 (через importmap с CDN), WebXR, Web Audio, Web Serial, Arduino.
